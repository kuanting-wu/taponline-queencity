# TapOnline — product walkthrough (prepared for Queen City Grappling Club)

Static site, no build step. Published with GitHub Pages.

- `index.html`: a walkthrough of the TapOnline product, screen by screen. It covers what the owner gets, the member app (M01–M21), the staff app (S01–S07) and the owner console (O01–O19), each with an interactive mock.
- `compare.html`: the current default look next to a custom QCGC monochrome version made with TapOnline's appearance settings, shown with before/after sliders, plus an explanation of how the Appearance builder relates to a fully custom member app.

All mocks are simplified HTML/CSS recreations that use sample data. No product source code, credentials or internal data are included.
